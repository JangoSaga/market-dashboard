# Market Dashboard

A modern, responsive financial market dashboard built with cutting-edge web technologies. This project provides real-time market data visualization, analytics, and insights for informed investment decisions.

## Features

- **Real-time Market Data**: Live updates of market prices and trends
- **Interactive Charts**: Responsive, interactive visualizations powered by modern charting libraries
- **Portfolio Tracking**: Monitor and analyze your investment portfolio
- **Market Analytics**: Advanced analytics and technical indicators
- **Responsive Design**: Seamless experience across desktop and mobile devices
- **Dark Mode**: Eye-friendly dark theme support

## Tech Stack

- **Frontend**: TypeScript, React, Next.js
- **Styling**: Tailwind CSS
- **State Management**: Modern React hooks and context
- **Data Visualization**: Interactive chart libraries

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
git clone https://github.com/JangoSaga/market-dashboard.git
cd market-dashboard
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Project Structure

- `/pages` - Next.js pages and routes
- `/components` - Reusable React components
- `/lib` - Utility functions and helpers
- `/public` - Static assets
- `/styles` - Global styles and Tailwind configuration
